# Hidden Titan Online

Браузерная игра с ботами и сетевым режимом на 4–8 человек. Python/FastAPI, WebSocket, HTML/CSS/JavaScript Canvas. Роли и игровые действия проверяет сервер.

## Запуск

В терминале VS Code в папке проекта:

```bash
python -m pip install -r requirements.txt
python -m uvicorn server:app --host 0.0.0.0 --port 8000
```

Откройте http://localhost:8000. Для теста используйте четыре вкладки. Создайте онлайн-комнату, скопируйте код, войдите в остальных вкладках, нажмите «Готов» и запустите матч хостом. Для устройств в одной Wi-Fi сети используйте LAN IP компьютера вместо localhost (разрешите порт 8000 в брандмауэре для частной сети).

## Публикация для друзей через интернет

Загрузите файлы в GitHub. На Render создайте Web Service из репозитория, Runtime Python, Build Command `pip install -r requirements.txt`, Start Command `uvicorn server:app --host 0.0.0.0 --port $PORT`. Используйте один экземпляр сервера. После развёртывания откройте выданный HTTPS URL, создайте комнату и отправьте ссылку друзьям. GitHub Pages не запускает Python, поэтому для онлайн-режима не подходит. Тарифы и доступность хостинга проверяйте у провайдера.

## Управление

WASD/стрелки, мышь или экранные кнопки. E — задания, Q — атака, R — доклад. Во время саботажа разведчик может восстановить ворота клавишей E в зоне ворот.

## Ограничения

Сетевой MVP, комнаты хранятся в памяти одного процесса, без аккаунтов и переподключения. Онлайн-режим без ботов, одиночный режим сохранён. Графика и столкновения упрощены. React/Phaser пока не используются. Неофициальный учебный проект.
